### QuickOpener 应用概述

QuickOpener 是一个 macOS 工具应用，旨在通过菜单栏图标和全局快捷键快速打开文件或项目文件夹。它支持自定义打开应用程序、项目过滤和数据持久化，使用 SwiftUI 和 SwiftData 构建。研究表明，该应用的核心设计强调高效性和用户便利性，类似于 Alfred 或 Raycast 等生产力工具，但专注于项目管理。

**关键功能要点：**

- **快捷访问**：通过全局快捷键（默认 Option + Z）或菜单栏图标快速显示/隐藏浮动窗口，支持 Esc 键关闭。
- **项目管理**：添加、删除、过滤和打开文件/文件夹，支持多应用选择打开方式。
- **自定义设置**：支持语言切换、快捷键重置和应用重启生效。
- **数据持久化**：使用 SwiftData 存储项目和应用信息，确保跨会话保留。
- **用户体验优化**：窗口自动定位于鼠标附近，失去焦点时自动关闭；支持鼠标悬停高亮和光标变化。

#### 核心交互机制

应用启动时在菜单栏显示图标，提供快速入口。窗口为浮动式（floating level），尺寸固定为 300x500，支持背景拖动但禁用最小化和缩放。添加项目时，使用 NSOpenPanel 支持多选文件/文件夹，避免重复路径。打开项目会递增权重，用于排序优先级（更高权重排前）。

#### 安全性与兼容性

应用不涉及网络操作，数据本地存储在 SwiftData 中。默认使用 Finder 作为打开工具，支持添加其他 .app 文件。权重机制鼓励频繁使用项目置顶，增强效率。潜在问题包括路径变化导致文件不存在时自动移除项目。

#### 扩展潜力

代码结构模块化，便于扩展如更多过滤选项或集成其他系统 API。语言支持包括系统默认、英文、简中、繁中、日文、韩文、德文、法文和西班牙文，通过 AppStorage 和 AppleLanguages 设置。

### 应用架构与启动流程

QuickOpener 的入口点在 `QuickOpenerApp.swift`，采用 `@main` 结构定义为无默认窗口的应用，主要依赖菜单栏和快捷键驱动。启动时：

- 创建共享的 SwiftData 模型容器（`sharedModelContainer`），支持 `ApplicationModel` 和 `ProjectModel` 的持久化存储。
- 初始化 `DataManager` 实例，用于集中管理数据。
- 通过 `AppDelegate` 处理应用生命周期：
  - 设置菜单栏状态项（`statusItem`），图标为自定义 "MenuIcon"，大小调整为 18x18 以适配菜单栏。
  - 构建菜单栏下拉菜单，包括 "显示窗口"、"设置"、"重置缓存"、"退出" 选项。
  - 注册全局快捷键：`.toggleProjectOpener`（默认 Option + Z）用于切换窗口显示/隐藏，`.closeWindow`（默认 Esc）用于关闭窗口。
  - 初次启动自动显示主窗口。

窗口创建逻辑在 `createNewWindow()` 中实现：窗口尺寸固定为 300x500，定位于鼠标光标附近（x 偏移 -60，y 偏移 -450 +23），风格为 titled 和 closable，支持背景拖动。窗口标题为 "QuickOpener"，右上角添加自定义标题栏附件（显示 "⌥ + Z" 提示）。窗口级别设为 `.floating`，确保始终浮于其他窗口上方。失去焦点时（`windowDidResignKey`）自动关闭，关闭时清除引用（`windowWillClose`）。

### 用户界面与交互

主视图在 `ContentView.swift` 中定义，使用 SwiftUI 构建，固定尺寸 300x500：

- **头部控件（headerControls）**：包含过滤文本输入框（`TextField`）和添加按钮（`Menu` with primaryAction）。
  - 过滤支持项目名称或路径的忽略大小写匹配，实时更新列表。
  - 添加按钮主操作触发 `addProjects()` 添加文件/文件夹；菜单提供当前应用显示、可用应用切换、添加新应用选项。
- **项目列表（projectsList）**：使用 `List` 显示过滤后的项目，按权重降序排序。
  - 每项行布局：应用图标菜单 + 项目名称 + 删除图标（trash）。
  - 支持鼠标悬停高亮（背景蓝色透明）、光标变化（pointingHand）。
  - 点击行或图标打开项目；删除图标触发 `removeProjects()`。
  - 项目设置菜单（`projectSetting`）：显示默认应用图标，支持切换其他应用打开或直接打开。
- **光标与悬停优化**：`onHover` 和 `updateCursor` 确保交互友好，悬停时切换为手形光标。

设置视图在 `SettingsView.swift` 中，使用 `Form` 组织：

- **语言设置**：通过 `Picker` 选择系统默认、英文、简中、繁中、日文、韩文、德文、法文、西班牙文。变更后更新 `AppleLanguages`，并提供 "重启生效" 按钮（`restartApp`），通过 `/usr/bin/open` 重启应用。
- **快捷键设置**：使用 `KeyboardShortcuts.Recorder` 配置 `.toggleProjectOpener`，并提供重置按钮。
- **关于部分**：显示应用简短和详细描述（本地化字符串）。

所有视图注入 `modelContainer` 和 `environmentObject(DataManager)`，确保数据一致性。

### 数据管理与模型

`DataManager.swift` 是核心管理类，采用 `@MainActor` 和 `@ObservableObject`：

- **属性**：`@Published` 项目列表（`projects`）、应用列表（`applications`）、当前应用（`currentApplication`）、过滤文本（`filterText`）。
- **初始化**：从 SwiftData 加载数据，确保默认 Finder 应用存在；从 UserDefaults 加载当前应用路径。
- **添加功能**：
  - `addApplication()`：打开面板选择 .app 文件，避免重复；插入新 `ApplicationModel` 并选中。
  - `addProjects()`：打开面板多选文件/文件夹，避免重复路径；设置当前应用和初始权重（最大权重 +1）。
- **删除功能**：`removeApplication()` 和 `removeProjects()` 删除模型并保存。
- **选择与缓存**：`selectApplication()` 更新当前应用并保存到 UserDefaults；`clearCache()` 清空所有数据，重置为默认。
- **渲染逻辑**：`renderProjects` 计算属性过滤并排序项目。

模型定义：

- `ProjectModel.swift`：存储路径、`applicationPath`、权重。支持 `open()` 方法：检查存在性、更新路径/权重、使用 `NSWorkspace` 打开文件。权重递增实现使用频率排序。
- `ApplicationModel.swift`：存储路径，默认 Finder。提供类似属性访问。
- `FileCommonData.swift`：协议扩展，提供通用计算属性如 `url`、`name`、`icon`、`exists`。

### 辅助功能与行为优化

- **菜单栏菜单**：
  - "显示窗口"：调用 `showWindow()`，复用或创建窗口。
  - "设置"：打开设置窗口（尺寸 500x300，居中定位）。
  - "重置缓存"：调用 `clearCache()` 并重新显示窗口。
  - "退出"：终止应用。
- **窗口定位与激活**：`positionWindowAtCursor` 根据鼠标位置调整；`activateWindow` 使窗口前台并激活应用。
- **错误处理**：文件不存在时自动移除项目；SwiftData 初始化失败时 fatalError。
- **本地化**：广泛使用 `NSLocalizedString` 和 `LocalizedStringKey`，支持多语言。
- **性能优化**：使用 `DispatchQueue.main.async` 确保 UI 操作主线程；列表使用 `id: \.self` 优化渲染。
